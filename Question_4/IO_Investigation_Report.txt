4. System Resource Limits (ulimit -a):
Key resource limits set for the shell environment:

- File size limit (-f): Unlimited

5. How Linux Manages File I/O:
- Linux treats everything as a file (hardware devices, folders, sockets, and standard inputs/outputs).
- Processes refer to these using small integers called File Descriptors.
- When we redirect streams using '>' or '2>', the shell changes which file descriptor points to which target file. This lets us capture outputs and errors into logs easily.
